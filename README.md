# Computer Networks Final Prep

Static site for the Cisco CCNA practice quiz / lecture-based exam flow. It includes modules 1-16 and a 45-question Mock Final section with randomized question and answer order on each attempt. Mock Final progress is tracked independently, explanations appear after answers, and its score contributes to the overall exam result.

## GitHub Pages
This repository is prepared for GitHub Pages deployment using the Pages workflow in `.github/workflows/pages.yml`.

## Local preview
Open `index.html` in a browser, or serve it locally with a simple static HTTP server.
